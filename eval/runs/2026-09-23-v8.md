## What it shows

- **Every functional check passed in all 12 runs.** The fixed checks catch regressions but can't rank setups; cost, size and process can.
- **Delivery rule:** Claude and Codex committed on a branch in 8 of 8 runs. OpenCode/DeepSeek committed in 0 of 4 and worked on `main` in 2. Its reports said that `on-request` meant it shouldn't commit.
- **Run-to-run spread is large.** Claude's two create runs cost $1.02 and $0.54 with 936k and 363k tokens. Compare revisions only on gaps bigger than that.
- **Subagents:** every Claude and Codex run used a review subagent. In `claude-create1` it found three real bugs, each fixed with a test that failed first. One Codex run used `gpt-6-sol` for its subagent instead of the configured Terra at high effort.

## Jev check of the self-reports

Each report bullet (or sentence, where a report had no bullets) was classified against the check record as supported, contradicted, not_covered, or not_a_claim. Totals: 52 supported, 55 not_covered, 5 not_a_claim, and 3 contradicted. All 3 "contradicted" verdicts are classifier errors, because no check failed. Two describe bugs the agent found and fixed in `claude-create1`, and one is a stated limitation in `opencode-update2`. Treat "contradicted" as real only when a check actually failed.

## Reviews

### Sonnet 5

**Findings**

1. **OpenCode broke the branch rule in half its runs.** `runs.json` shows `opencode-create1` (`"branch":"main","commits_after_baseline":0,"uncommitted_paths":8`) and `opencode-update2` (`"branch":"main"`, 4 uncommitted paths) did all work directly on the default branch, violating "work on a branch... never push directly to the default branch." Claude (4/4) and Codex (4/4) always branched and committed.
2. **Correctness is a wash.** Every `checks/*.json` shows 100% pass — `"passed":"6/6"` (create) or `"10/10"` (update) in all 12 files. No setup differentiates on functional correctness here.
3. **OpenCode's self-reports under-claim relative to what was actually verified.** `reports/opencode-create1.md` says "a real browser reload was not exercised" and "No browser rendering/screenshot check (none available here)" — yet `checks/opencode-create1.json` shows `"persist_reload":"pass"` and `shots/opencode-create1.png` exists, meaning the evaluator's browser did what the agent said it couldn't.
   *Operator note: this is honest disclosure, not under-claiming. The agent's own tests used jsdom, and the evaluator's browser check is separate.*
4. **Cost basis differs but effort doesn't.** `runs.json`: opencode costs $0.0136–$0.0264/run vs Claude's $0.513–$1.018 vs Codex ("unavailable," subscription), yet token totals are comparable or higher for OpenCode (`opencode-create2.tokens_total: 984926` vs `claude-create1.tokens_total: 936402`) — the price gap is pricing/quota, not less work.
5. **jev's "contradicted" verdicts are noise, per the bundle's own framing.** `jev/claude-create1.json` flags 2 contradicted claims (confidence 0.75, 0.63, e.g. "Opening the page from disk loaded no code in Chrome... I confirmed this directly"); `jev/opencode-update2.json` flags 1 more. README states every check passed everywhere, so these 3/12 flags are classifier errors — jev's contradiction signal isn't trustworthy in this pilot.
